## Method 1: Complete Desktop Deletion (Remaining ~1,800 emails)

### Step-by-Step Process:

1. **Open Outlook** (should already be open)

2. **Apply Unread Filter:**
   - Click the three-line menu button (≡) next to "Inbox"
   - Select "Unread"
   - This shows only unopened emails

3. **Delete in Smaller Batches (200 emails at a time):**
   - Click in the email list
   - Press `Cmd+A` to select all visible emails (will be ~200-500)
   - Press `Delete` key or click "Delete" button
   - Click "Delete" in confirmation dialog
   - Wait for emails to be removed
   - Repeat until all unread emails are gone

4. **Verify Progress:**
   - Inbox count should approach 0 for unread emails
   - Deleted Items folder will continue growing

---

## Method 2: Outlook Web (Recommended - Faster & More Reliable)

### If Desktop Method Becomes Difficult:

1. **Open Browser** → Go to `outlook.com`
2. **Log in** with your email
3. **Search for unread:**
   - Click search box
   - Type: `is:unread`
   - Press Enter
4. **Bulk delete:**
   - Click top checkbox to select all on page
   - Click "Delete" (trash icon)
   - Repeat until all gone
5. **Done!** Web version handles bulk ops more reliably
